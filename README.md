## Project Overview
This project supports the development of a dengue disease expert system by examining patient records across demographic, clinical, and symptom-related attributes. Key exploratory and analytical tasks in the notebook include:
* Cleaning and standardizing patient data (such as age encoding conversions, missing value checks, and attribute filtering).
* Analyzing symptom occurrence and distribution across patient records.
* Exploring demographic patterns such as age, gender, race, residence area, and symptom duration.
* Visualizing key distributions and data characteristics to inform knowledge representation and clinical rule design.
